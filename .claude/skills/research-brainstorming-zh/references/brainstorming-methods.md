# 發想與引出方法（brainstorming-methods）

方法是「合目的的流程選擇」，不是創意保證。實驗室研究裡最穩健的發現很窄：面對面互動的群體，產出的非重複構想常**少於**同樣人數各自獨立作業的匯集，主因是輪流發言的「production blocking」。但這不代表獨立作業對學習、綜整、承諾、選擇或每種真實任務都更好。

## 依目的選方法

| 需求 | 適合的模式 | 主要注意 |
|---|---|---|
| 廣的初始構想池 | 獨立生成 → 結構化分享 | 池子大不自動等於決策好 |
| 平等參與＋當天排序 | Nominal group technique（NGT） | 票數是面板偏好，不是科學真理 |
| 分散、需時間修正的迭代判斷 | Delphi | 共識可能圍繞共同偏誤穩定下來 |
| 為模型取得不確定的量值 | 結構化專家引出 | 專家判斷不取代實證證據 |
| 探索組合設計空間 | 形態分析（morphological） | 組合可能不可行或無意義 |
| 重構既有概念 | SCAMPER／假設反轉 | 提示啟發法的效果因情境而異 |
| 壓力測試入選構想 | 紅隊、premortem、替代解釋 | 每個挑戰都要有回應與負責人 |

## 獨立生成再互動（現場預設流程）

1. 給每人同一中性問題、限制與時間。
2. 各自私下、平行寫構想。
3. 在看到別人答案前先登錄每個構想。
4. 匯集並給穩定 ID，可遮蔽貢獻者身分。
5. 以 round-robin 澄清語意，不辯護不評分。
6. 讓大家看過池子後再加一輪私下生成。
7. 依宣告的關係分群，保留原文。
8. 明確宣告進入「評估階段」。

價值：平行作業避免等待發言；human-first 生成限制早期領導者/範例/AI 錨定；第二輪私下生成允許受他人刺激又不必即時公開表演。限制：經典研究多用短、人工任務與學生樣本；匯集的個人產出可能重複、也錯過對話整合的好處；構想數多不保證最終選得好。

## Nominal group technique（NGT）

四階段常見形式：(1) 靜默生成——各自回答一個精確問題；(2) round-robin 記錄——每人一次貢獻一項到全數收齊；(3) 澄清——只談語意不談優劣，合併須經原提出者同意並留合併紀錄；(4) 獨立評分/排序——依預先宣告規則私下投票。適用於重視平等發言、可追溯與即時排序時。報告應含：招募與視角、事前提供的問題與材料、群體規模與主持人與利益衝突、項目如何被編修/合併/移除、量尺與保留規則與缺票/平手/棄權、**完整分布**（不只前段）。不要把排序清單稱為「已驗證」，不要因低排序就丟掉涉及安全或倫理的少數關切。

## Delphi

迭代、通常匿名、回合間有受控回饋。適用於參與者分散、面對面地位效應堪憂、或判斷需時間修正時。最小可辯護設計：說明為何用 Delphi、預先定義資格與回合停止邏輯與共識規則與缺值處理、回合 1 獨立收集、回饋含分布與匿名理由（不只平均）、允許保留或修正並解釋重要改變、報告各回合流失與分歧與未達共識項目。**共識只代表此面板在此協定下的收斂**，不建立正確性、因果或臨床有效性。「Modified Delphi」須逐條列出修改。

## 結構化專家引出

當實證證據不足、決策模型需要「量值或機率分布」（不只構想清單）時使用。高階序列：定義目標量與單位與條件與時間範圍→先系統性回顧證據→選相關且互補的專家並揭露利益衝突→訓練表達不確定並測試工具→個別引出再群體聚合→先要合理邊界與理由再要中心估計、避免提供偏好錨點→記錄假設與依賴與「什麼證據會改變估計」→用宣告的聚合方法→測試對專家/規則/假設的敏感度→區分專家判斷與資料。

## 發散與收斂

- **發散**：固定期間內延後比較判斷；變化尺度/對象/機制/測量/時間範圍/介入層級；要求會預測不同觀察的替代方案；納入 null 機制與「先不動/先測量」選項；生成當下就捕捉假設與不確定。
- **轉換**：主持人明確關閉生成、凍結初始登錄、引入評估準則。此流程分離能減少過早評價，但不宣稱一定提升入選品質。
- **收斂**：澄清分群不抹除差異；為此決策定義原創性與有用性；先獨立評分再討論；顯示分數分布與質性理由；跑對抗式/證據/可行性/倫理審查；準則或證據變動時重訪。

## 生成式提示家族（是鷹架，不是已驗證科學方法）

- **假設清單與反轉**：列描述/因果/測量/操作/價值假設 → 標為已證實/慣例/必要/不確定 → 反轉或移除一個 → 問會觀察到什麼、反轉是否連貫。挑釁的反轉不等於合理假說。
- **尺度與邊界移轉**：變空間/組織層級、時間尺度與延遲、對象/環境/邊界條件、劑量/強度/解析度、分析單位與測量方式；問哪些機制不變、哪些預測改變。
- **跨域類比**：明寫來源系統/目標系統/被轉移的關係/已知不匹配/可檢驗蘊涵/轉移前需要的證據。類比只生成問題，不是目標機制的證據。
- **形態分析**：定義獨立維度→列各維度有限選項→系統產生組合→刪違反限制者→太大就透明抽樣→記錄排除理由。未列出的組合不等於新穎。
- **SCAMPER**：對既有方法問是否 Substitute／Combine／Adapt／Modify／Put to another use／Eliminate／Reverse。每個產出補上機制、預期觀察與失敗模式。
- **約束階梯**：三輪——現有真實約束 / 移除一個可協商約束 / 加一個更嚴的安全/成本/時間/可及性約束；比較哪些構想存活。
- **premortem 與替代**：假設偏好構想產生了無法解讀或有害的結果，跨理論/測量/抽樣/執行/分析/治理/誤用列原因；再要至少兩個會預測同樣「表面成功」的機制，各轉成一項可辨別觀察。

## 方法組合與停止條件

有用組合：獨立生成 → NGT 澄清/評分 → 對抗式檢視；形態分析 → 獨立評分 → 可行性閘門；文獻查核 → 假設反轉 → 更新決策矩陣。**不要只為了看起來嚴謹而堆疊方法**，每階段都要有目的、產物與停止規則。

觸發暫停或結束：議題無法在不涉機密/受控細節下界定；群體缺少對安全或解讀關鍵的視角；觸發臨床/倫理/生物安全/資安/法規閘門；參與者無法安全表達異議；為偏好選項而改準則或權重；文獻查核太不完整以致無法支撐新穎性宣稱；決策負責人不在場。
