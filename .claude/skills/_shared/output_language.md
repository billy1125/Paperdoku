# 輸出語言慣例（共用）

> Paperdoku suite 共用規範。各 skill 以 `../_shared/output_language.md` 引用。

## 預設語言

- 輸出**預設繁體中文、台灣用語**；使用者以其他語言提問時，配合其語言。
- 使用者明確指定語言時，以使用者指定為準。

## 專有名詞

- **保留必要的英文專有名詞與方法術語**，不硬翻成生硬中文。例如：collaborative filtering、XAI、p-value、PLS-SEM、common method bias、robustness check。
- 首次出現的關鍵術語可在括號內附中文說明，之後沿用英文。

## 風格

- 簡潔直接，不過度解釋。
- 表格、清單等結構化輸出的欄位名稱全 suite 一致，便於跨 skill 比較。
