# 論文檔案命名規則(共用)

> Paperdoku suite 共用規範。任何 skill 處理後產出的論文檔案,統一依此命名。各 skill 以 `../_shared/paper_naming_convention.md` 引用,勿各自重寫。

## 基本格式

```
YYYY-AuthorLastName-Papername.pdf
```

| 欄位 | 說明 | 格式要求 |
|---|---|---|
| `YYYY` | 論文發表年份 | 4 位數字,如 `2023` |
| `AuthorLastName` | 第一作者姓氏 | 英文姓氏用 PascalCase;中文姓氏用拼音,如 `Chen`、`Wang` |
| `Papername` | 論文名稱 | 簡短標籤 |

## 命名範例

- `2024-Al-Determinants of Students Satisfaction with AI Tools A PLS-SEM-ANN Approach.pdf`
- `2024-Wang-Forecasting the Acceptance of ChatGPT An Integrated SEM-ANN Methodology.pdf`

## 注意事項

- 檔名全部使用**英文與數字**,不使用中文或特殊符號。
- 連接詞統一用 `-`(hyphen)。
