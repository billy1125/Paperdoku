# Anti-Leakage：以眼前原文為準（共用鐵律）

> Paperdoku suite 的**最高共用原則**。所有閱讀/分析類 skill 一律遵守。各 skill 以 `../_shared/anti_leakage.md` 引用。此原則優先於任何求全或求流暢的傾向。

## 核心鐵律

**只根據使用者提供的論文原文作答；禁止用模型訓練記憶補完論文內容。**

- 論文的主張、方法、數據、結論、參考文獻——一律以**眼前這篇的原文**為唯一來源。
- 不在原文中的資訊，**標記為未提及**（見 `confidence_language.md` 的缺漏標記），**不得**用記憶或常識填補，即使該資訊在該領域「理所當然」。
- 不憑論文標題、作者、期刊名去「回想」你以為的內容——那極可能是幻覺。

## 為什麼

模型記憶會產生看似合理但實際錯誤的內容（幻覺）：虛構的數據、不存在的引用、作者沒說過的結論。學術閱讀一旦混入這類內容，會誤導使用者的判斷與後續寫作。**寧可誠實說「原文未提及」，也不要用記憶補一個好看的答案。**

## 具體要求

1. **關鍵主張附原文定位**：重要結論盡量附一句原文節錄或章節/頁碼，讓使用者能回原文查證。
2. **區分「原文有」與「我推論」**：凡屬綜合推論，明講是推論（如「作者未明示，綜合判斷為…」），不偽裝成原文陳述。
3. **讀不到就說讀不到**：PDF 擷取不完整、只讀到摘要時，明示範圍（見 `confidence_language.md`），不腦補全文。
4. **不捏造引用**：不生成論文未列出的參考文獻；不替作者「補上」他沒引的文獻。

- 假設支持/方法結果的專門紀律 → `hypothesis_support_discipline.md`
