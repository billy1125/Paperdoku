# 可讀層次與信心用語（共用）

> Paperdoku suite 共用規範。凡需依「讀到多少」調整語氣確定度的 skill，統一用此分級與用語。各 skill 以 `../_shared/confidence_language.md` 引用，勿各自重寫。

## 一、可讀層次

先判斷每篇文獻能讀到的程度；所有後續判斷都受此約束：

| 層次 | 說明 |
|---|---|
| 全文可讀 | 可讀到完整 PDF 或完整內文 |
| 部分可讀 | 部分頁面、部分文字或不完整 PDF |
| 僅摘要可讀 | 只有摘要頁、DOI 頁或出版社頁面 |
| 幾乎不可讀 | 只有書目資訊或頁面存取受限 |

## 二、信心等級與語氣

每篇文獻（或每項判斷）標記一個信心等級，並用對應語氣：

| 等級 | 條件 | 語氣要求 |
|---|---|---|
| 高 | 全文可讀，關鍵欄位完整 | 可用較確定語氣，但避免過度延伸 |
| 中 | 大部分可讀，有少量缺漏 | 加限定語，如「依可讀內容判斷」「目前資訊顯示」 |
| 低 | 僅摘要、片段或資訊不足 | 明確使用保留語氣，如「初步判斷」「僅能根據摘要推估」 |

信心為中或低時，**明確寫出缺少什麼**，例如：僅依摘要整理、樣本資訊未完全揭露、理論框架需全文確認、PDF 文字擷取不完整。

## 三、缺漏標記（欄位層級）

某項資訊論文未清楚報告時，不留白也不臆測，改用標準標記：

- **not reported / 未明示**：論文完全未提及
- **unclear / 無法確認**：論文有提及但描述模糊
- **inferred with low confidence**：有間接線索，但非明確陳述

> 反捏造的完整鐵律見 `anti_leakage.md`。
