# 假設支持與方法/結果分離紀律（共用）

> Paperdoku suite 共用規範。凡涉及「假設是否被支持」「方法 vs 結果」判斷的 skill，統一遵此。各 skill 以 `../_shared/hypothesis_support_discipline.md` 引用，勿各自重寫。

## 一、不從係數符號猜支持狀態

- **不**僅依迴歸係數方向或大小推斷假設是否被支持。
- 需有**作者明示的顯著性資訊**（p 值、信賴區間、作者結論句）才能判定支持/不支持。
- 缺顯著性資訊時，標記「根據現有文字無法確定」，不猜。

## 二、方法與結果分離

以下屬「研究結果」，**不是**方法的核心內容，勿混入方法描述：

- 假說是否獲得支持
- 迴歸係數方向與顯著性
- 統計量（β、p、t 等）

只有在有助於理解分析流程時（例如說明為何增加某個控制變數），才可附帶提及。

## 三、三層次不混淆

| 層次 | 定義 | 範例 |
|---|---|---|
| 研究設計(study design) | 資料取得與因果推論的架構 | survey、experiment、quasi-experiment、panel |
| 量測設計(measurement design) | 構念如何操作化與測量 | 量表來源、題項設計、信效度檢驗 |
| 分析方法(analytical method) | 資料分析所用的統計技術 | regression、SEM、ANOVA、HLM、DID |

## 四、非實證論文

非實證研究（純理論、綜述、方法論文章）在總表中**標明性質**，不強行套用假設架構去找不存在的假設或支持狀態。
