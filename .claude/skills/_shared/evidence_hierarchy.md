# 證據等級（Evidence Hierarchy，共用）

> Paperdoku suite 共用規範。比較多篇或衡量某宣稱的證據強度時，依研究設計加權。由 `literature-review-organizer`（綜整/SR）、`paper-research-logic-review`（跨篇）、`academic-peer-review-zh`（結論是否被證據支撐）共用。以 `../_shared/evidence_hierarchy.md` 引用。

## 等級（針對因果/療效類問題）

由強到弱：

| 級 | 設計 | 說明 |
|---|---|---|
| 1 | 系統性回顧 / meta-analysis（整合 RCT） | 最高，前提是納入研究品質佳 |
| 2 | 隨機對照試驗(RCT) | 隨機分派控制混淆 |
| 3 | 準實驗 / 世代研究(cohort) | 有時序，但分派非隨機 |
| 4 | 病例對照(case-control) | 回溯，易選樣/回憶偏誤 |
| 5 | 橫斷面 / 調查(cross-sectional) | 同時測量，難推因果 |
| 6 | 病例報告 / 個案(case report) | 無對照 |
| 7 | 專家意見 / 敘事評論 | 最低 |

## 三個重要 caveat（勿機械套用）

1. **等級是給「因果/療效」問題的**。若研究問題是**意義、機制、盛行率、概念建構**，適合的設計不同——質性研究回答「為什麼/怎麼發生」正當且有力，**不可因它不是 RCT 就打折**。先看問題型態再選標尺。
2. **設計 ≠ 品質**。做得好的 cohort 可勝過有嚴重瑕疵的 RCT。等級要**與 `../_shared/risk_of_bias.md` 併用**：先定等級，再依 RoB 上下修。
3. **領域差異**。社會科學、教育、管理常無 RCT 條件；在該領域內比較時，以該領域可行的最強設計為頂，不硬套醫學標尺。

## 使用方式

- **跨篇綜整時**：標出每篇的證據等級；當多篇結論衝突，**優先採信等級高且 RoB 低者**，並明講依據。
- **衡量宣稱時**：若一個強宣稱（尤其因果）只靠低等級證據（如單一橫斷面調查），明確指出「證據等級不足以支撐此宣稱」。
- **輸出**：在比較表或綜整加一欄/一句證據等級，讓強弱可見。

## 紀律

- 依論文**實際做的設計**分級（可取自 `method-extraction` 或原文），不憑標題臆測。
- 先判問題型態再套等級，不對非因果問題硬套 RCT 標尺（見 caveat 1）。
