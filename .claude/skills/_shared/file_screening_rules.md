# 檔案初步篩選規則(共用)

> Paperdoku suite 共用規範。以檔案/資料夾為輸入的 skill(方法萃取、研究邏輯審查等)在動工前先套此篩選。各 skill 以 `../_shared/file_screening_rules.md` 引用,勿各自重寫。

## 篩選條件

遇到下列情況,**先詢問使用者是否繼續**,確認不處理才略過:

- 無法讀取(檔案損毀、加密、存取受限)
- 非 PDF 格式
- 非學術論文(可由標題與關鍵字辨識)
- 檔案大小 **超過 10MB 或小於 100KB**

## 資料夾慣例

- `Unprocessed_Papers/` — 使用者選擇不處理、或無法辨識/不符格式的檔案移入此處,並附上簡短說明。
- `Readed_Papers/` — 處理完成的論文;**移動前先請求使用者同意**(且需有本地資料夾與移動權限),再依 `paper_naming_convention.md` 命名移入。

## 原則

- 篩選只做「是否納入處理」的判斷,不對內容做實質評價。
- 任何檔案移動都需使用者同意,不自行搬檔。
