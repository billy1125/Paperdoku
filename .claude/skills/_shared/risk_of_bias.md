# 風險偏誤評估(Risk of Bias,共用)

> Paperdoku suite 共用規範。對**實證研究**做結構化系統性偏誤評估,補足方法紅旗清單之外的偏誤視角。由 `academic-peer-review-zh`(單篇審稿)與 `literature-review-organizer` 的 `systematic-review` 模式共用。各 skill 以相對路徑 `../_shared/risk_of_bias.md` 引用。

## 適用與定位

- 適用:量化/實驗/準實驗/調查/縱貫等**實證**研究。純理論、綜述、方法論文章不適用。
- 這是**偏誤導向**的評估(研究結論可能被系統性地推向某方向),與 `confidence_language.md`(讀到多少)、`hypothesis_support_discipline.md`(支持狀態判定)互補。
- 遵守 `anti_leakage.md`:每個評等都要有原文/表格為據;**未報告 ≠ 高風險**,資訊不足標「unclear」而非逕判高風險。

## 六個偏誤面向

依研究設計取用相關面向(非全部都適用每種設計):

| 面向 | 看什麼 | 常見高風險徵狀 |
|---|---|---|
| **1. 選樣偏誤(selection)** | 樣本如何取得、代表性、自我選擇 | 便利樣本卻宣稱可外推、招募管道偏斜、應答率極低未討論 |
| **2. 測量偏誤(measurement)** | 構念操作化、信效度、共同方法變異 | 單一自陳來源測所有變項(CMB)、量表未報信效度、操弄檢核缺 |
| **3. 混淆與因果(confounding)** | 是否控制干擾、因果宣稱是否被設計支撐 | 橫斷面卻下因果結論、關鍵混淆變項未納入、反向因果未處理 |
| **4. 流失偏誤(attrition)** | 縱貫/實驗的流失率與差異流失 | 高流失且未比較留存/流失者、缺失值處理未交代 |
| **5. 報告偏誤(reporting)** | 選擇性報告、p-hacking、HARKing | 假設數與報告數不符、只報顯著結果、無預註冊卻大量事後假設 |
| **6. 分析偏誤(analysis)** | 方法是否適切、假設是否滿足 | 違反統計假設未檢、多重比較未校正、模型規格可疑 |

## 每個面向的評等

沿用 suite 的四級語言(與 `confidence_language.md` 一致):

| 評等 | 意義 |
|---|---|
| 低風險(low) | 該面向處理得當,有明確報告支撐 |
| 有疑慮(some concerns) | 部分處理但有缺口,可能影響結論 |
| 高風險(high) | 明顯偏誤來源未處理,足以左右結論方向 |
| 不清楚(unclear) | 報告資訊不足,無法判定(**不等於高風險**) |

每個面向輸出:**評等 + 1–2 句原文為據的理由**,並區分「真正的偏誤來源」與「只是報告不清楚」。

## 整體判定與輸出

- 逐面向評等後給一個**整體 RoB**(通常以最嚴重面向為主,不機械平均)。
- 表格輸出:
  ```markdown
  | 面向 | 評等 | 依據 |
  |---|---|---|
  | 選樣 | 有疑慮 | 便利樣本(第3節),外推宣稱過強 |
  | 測量 | 高風險 | 全變項單一自陳,未做 CMB 檢核 |
  | ... | ... | ... |
  整體 RoB:高風險——測量與因果面向的偏誤足以影響主結論。
  ```
- **紀律**:高風險要指出「偏向哪個方向」(如自陳共變高估關係強度);且依 `anti_leakage.md`,不憑常識補論文沒寫的做法,未報告標 unclear。
