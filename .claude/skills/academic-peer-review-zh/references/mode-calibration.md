# calibration 模式:審查者校準

目的:對使用者提供的 **gold set**(已知正解的稿件/意見),量本審查者的準確度——多常**漏掉真問題**(FNR)、多常**誤報非問題**(FPR),讓使用者知道目前的審查設定偏嚴還偏鬆,據以調整 profile。借 ARS 的 calibration 設計。這是進階、選用模式。

> 前提:使用者要能提供**有正解標記**的材料。沒有 gold set 就無法校準——這是量測,不是憑感覺。

## 需要的輸入(gold set)

至少一種:
- 幾篇**已知結果**的稿件(如已知被拒/被接受、或專家已標出的關鍵缺陷清單)。
- 一組**已標記的審查意見**(哪些是真問題、哪些是誤報)。
- 小 N 可接受(如 5–10 篇/條),但**須誠實揭露樣本小、結論僅供參考**。

## 流程

1. **盲評**:對每篇/每條,讓審查者在**不看正解**下產出判定(是否有問題、判決)。
2. **比對正解**,分類每個判定:
   - 真陽性(TP):審查者抓到 & 確實是問題。
   - 偽陰性(FN):審查者**漏掉**的真問題。
   - 偽陽性(FP):審查者**誤報**的非問題。
   - 真陰性(TN):正確判為沒問題。
3. **計算**:
   - FNR = FN /(TP+FN) —— 漏抓率。
   - FPR = FP /(FP+TN) —— 誤報率。
   - 整體一致率。
4. **詮釋與調整**:
   - **FNR 高 → 偏鬆**(放過真問題):建議調嚴(profile 往 Strict、提高標準)。
   - **FPR 高 → 偏嚴/吹毛求疵**(把非問題當問題):建議調鬆(profile 往 Balanced/Developmental)。

## 輸出格式

```markdown
## 審查者校準結果（gold set N=…）

| 項目 | 值 |
|---|---|
| TP / FN / FP / TN | … |
| FNR（漏抓率） | 0.xx |
| FPR（誤報率） | 0.xx |
| 整體一致率 | 0.xx |

**詮釋**:FNR 偏高，目前設定偏鬆，漏掉了 N 個效度類真問題；建議把 profile 調嚴或加強方法面向火力。
**限制**:gold set N 小，結論僅供參考；本結果只反映目前這組審查設定，非普適。
```

## 紀律

- **盲評**:比對正解前不得先看答案。
- **誠實小樣本**:小 N 明示,不誇大成穩定指標。
- 校準的是**目前這組審查設定**(profile + 火力),換設定要重新校準。

## 選用:跨模型覆核(cross-model)

要更接近「獨立第二意見」而非同一模型自評,可**手動**把同一篇丟給另一個模型(如非 Anthropic 模型)產出審查,再與本審查者比對分歧。

- **Claude Code 無法在 skill 內自動呼叫第二模型**——這一步是手動的:使用者自行取得第二模型的意見貼回比對。
- 用途:分歧點是需要人再看的訊號(borrow ARS 的 blind disagreement 精神),不是投票表決。
- 這是選用、非本 skill 自動流程;若無第二模型,單模型校準(上文)仍有效。
