# 通用審查面向：判準與常見問題

`SKILL.md`「八大評估面向」的延伸。每項列出「**看什麼 → 常見問題 → 建議方向**」。跨領域通用；量化/實驗/質性的方法細節另見 `method-checklist.md`。

> **論文的主軸是一條可驗證的論證鏈**：問題重要性 → 既有知識 → 研究缺口 → 研究回應 → 研究證據 → 研究貢獻。審查時逐環檢查「上一環是否被下一環接住」——只依序排列文獻、方法、結果卻沒有建立這些關係，就是論文最常見的鬆散來源。最終原則：**不要讓讀者替作者補上推理**。

## 1. 研究貢獻與重要性
- 看什麼：研究問題是否清楚？相對既有研究新增了什麼？「so what」站得住嗎？
- 常見問題：貢獻誇大或含糊；只是把既有模型換個情境卻宣稱重大理論突破；增量太小。
- 方向：請作者用 1–2 句明確陳述貢獻並對照最接近的前作；若貢獻偏增量，誠實定位即可，不必硬拔高。

## 2. 文獻定位與當代性
- 看什麼：是否對話到該領域**核心理論**與**近五年**文獻？引用是否精確（一手出處）？**研究缺口是否具體、可驗證**？
- 常見問題：遺漏對口的核心理論（＝選不全）；文獻停在十多年前，與當代脫節；經典構念出處引錯；缺口只寫「很少研究」。
- 方向：補核心理論的對話與近期實證；補正一手出處。
- **「理論太老」的拆解**：年份久≠弱點。把直覺改寫為具體問題：(a) 不切題、(b) 缺當代對話、(c) 舊理論過度包裝成新理論。
- **缺口品質（紅旗：「很少人研究」）**：有效缺口須說明「過去已處理什麼／哪裡不足／不足造成什麼影響／本研究為何介入」。常見缺口七類：理論、變數（缺關鍵前因/中介/調節/結果）、情境、方法、測量、證據、不一致（過去結果彼此矛盾）。
  - ❌ 弱：「很少研究探討此主題，因此本研究要探討。」
  - ✅ 好：「既有研究主要檢驗＿＿，但尚未區分＿＿與＿＿，因此無法判斷＿＿；本研究透過＿＿補足此不足。」

## 3. 理論／概念架構
- 看什麼：理論是否切題並真正驅動假設；「整合」是否長出新機制；因果方向是否合理。
- 常見問題：
  - **偽整合（horse race）**：兩條平行路徑各自預測同一依變項，僅靠一兩條交叉路徑相連，無交互新構念。
  - **過度宣稱新理論**：keywords/貢獻段出現自創理論名，但未建模對應機制。
  - **反向因果/內生性**：橫斷面卻宣稱單向因果，反向同樣合理。
- 方向：如實描述為「相對重要性比較」並提升為核心問題；移除新理論宣稱、定位為「以成熟理論檢驗新情境」；承認或以設計處理內生性。

## 4. 研究設計與方法（測量/操作化部分）
- 看什麼：設計能否回答研究問題；抽樣與外推；**測量是否量到所宣稱的構念**；可重製性。
- 常見問題：
  - 問題↔設計錯配（宣稱長期卻橫斷面；宣稱行為卻測意圖）。
  - **測量未對準構念**：題項措辭已把依變項意涵寫進前因，造成套套邏輯、係數灌水。
  - 樣本偏態或多來源直接合併、外推受限。
  - 程序/材料/分析碼不足以重製。
- 方向：用語一致並揭露侷限；重述題項聚焦客觀屬性；合併前做恆等性檢定；補充可重製資訊。

## 5. 分析與結果
- 看什麼：分析方法適切、假設滿足、報告完整、效度；**每項主張是否配有對應證據**；Results 是否依研究問題／假設順序（非軟體輸出順序）呈現。
- 常見問題：缺效果量/信賴區間/適配指標/中介檢定；忽略共線性與抑制；效度檢定不足；結果章過早展開大量理論解釋。（量化細節見方法清單）
- 方向：補齊該報指標；檢查共線性；結果段落「先說分析目的 → 再呈現數值 → 最後做最小判讀」。
- **主張 ↔ 所需證據對照**（審查時逐項核對「宣稱是否被對應證據撐住」）：

| 研究主張 | 所需證據 |
|---|---|
| 變數具有影響 | 路徑係數、信賴區間、顯著性 |
| 存在中介效果 | 間接效果與信賴區間（bootstrap） |
| 存在調節效果 | 交互作用或群組差異 |
| 模型具有解釋力 | R²、效果量 |
| 模型具有預測力 | Q²predict、RMSE、MAE（樣本外） |
| 非線性模型有增益 | 與線性基準模型比較 |
| 理論具情境適用性 | 跨群組／跨情境／穩健性分析 |
| 測量具有品質 | 信度、收斂效度、區別效度 |

## 6. 結論與宣稱
- 看什麼：結論是否被證據支撐；有無過度宣稱；Discussion 是否解釋結果意義（而非重複顯著／不顯著）；未獲支持的假設是否被進一步分析。
- 常見問題：相關當因果；意圖當行為；中等解釋力做強解讀；把可能的統計假象（如共線性造成的負係數）當「反直覺發現」大書特書；**宣稱預測力卻只報樣本內 R²**；**宣稱非線性卻無線性基準**；結論新增正文未分析的主張。
- 方向：把宣稱收斂到證據能支撐的範圍；先排除統計假象再解讀；未獲支持的假設從「情境限制／中介機制／門檻或非線性／測量／樣本／替代理論」六個角度探討，而非當成單純失敗。

## 7. 研究限制與倫理
- 看什麼：限制是否誠實切題；IRB/倫理、知情同意、利益衝突、資料可得性是否交代。
- 常見問題：限制流於形式、避重就輕；缺倫理聲明。
- 方向：補上切中要害的限制與倫理資訊。

## 8. 表述與清晰度
- 看什麼：結構、圖表正確性、編號一致性、語文；**圖形是否自洽**；**核心概念是否貫穿各章**；句段是否讓讀者自行推論。
- 常見問題：**假設/編號在正文與各表各圖間不一致（常見且嚴重）**；圖中標籤標錯；數字與正文不符；拼字文法；圖出現未定義變數或缺正文宣稱要檢驗的關係；重要概念未事先定義。
- 方向：全篇統一編號；逐一校對圖表；語文列 Minor，份量最小。
- **圖形原則**：圖中概念均在正文定義；圖中關係均與假設／RQ 一致；不加入無法檢驗的暗示；閱讀方向清楚；圖說能獨立說明用途。
- **核心概念策略性重複**：全篇最重要的概念應在各章重複但承擔不同功能（Abstract 點題 → Intro 說風險 → LR 定義與理論來源 → Model 關係 → Method 測量／操弄 → Results 假設成立與否 → Discussion 機制 → Conclusion 價值），形成螺旋式深化。
- **段落原則**：每句話都應有功能（定義／建立重要性／提供證據／說明機制／比較／指出缺口／銜接）；沒有功能的句子可刪。避免讓讀者自行補上推理——「ANN 較好」應寫成「ANN 在 10 折交叉驗證的平均 RMSE 低於 OLS，顯示非線性模型在此資料上樣本外預測較佳」。

## 章節審查對照（實證論文）

逐章快速定位「這一章該看什麼」。深究時回到上面對應面向。

- **Abstract**：是否含背景／缺口／目的／方法／核心結果／貢獻；避免只說做了什麼不說發現什麼、避免模糊語（「表現良好」）。
- **Introduction（四段式）**：①問題為何重要 → ②過去知道什麼、缺什麼 → ③本研究的回應（理論觀點／模型／設計）→ ④主要發現與貢獻概述。只讀 Intro，讀者應能說出問題重要性、明確缺口、如何補足、主要方法與核心發現、主要貢獻。
- **Literature Review／假設**：文獻是否為架構建立理論理由（非作者＋年份排列）；每個構念是否定義；每項假設是否有**機制**而非只有引用。
- **Research Model**：與假設、方法、結果是否完全一致；有無未定義變數或缺漏的宣稱關係。
- **Methodology**：設計是否回答 RQ；抽樣、操作化是否可追溯；排除標準是否事先說明；方法選擇是否附理由；可重現性。核心對應：研究問題 → 所需證據 → 資料來源 → 分析方法（見 `method-checklist.md`）。
- **Results**：是否依 RQ／假設順序；必要統計是否完整；是否區分解釋力與預測力；是否提供基準模型；是否避免過早解釋。
- **Discussion／Conclusion**：是否解釋「為什麼出現此結果」、與過去研究比較、指出理論理解受何修正、實務建議是否由結果直接推出、限制是否界定適用範圍、結論是否回到原始 RQ 且未新增未分析主張。

## 對應矩陣（檢查前後呼應）

| 研究缺口 | 研究問題／假設 | 研究設計 | 分析證據 | 研究貢獻 |
|---|---|---|---|---|
| 缺少信任機制說明 | H1–H3 | 中介模型 | 間接效果 | 理論機制 |
| 缺少預測證據 | RQ2 | 預測分析 | RMSE、MAE | 方法貢獻 |
| 不確定是否非線性 | RQ3 | ANN 與 OLS 比較 | 交叉驗證誤差 | 模型邊界 |

用此矩陣檢查：有無提出但未回答的問題、有無執行但缺理論目的的分析、有無宣稱但缺證據的貢獻、有無結果沒回到研究缺口。

## 常見失敗模式（快速紅旗清單）

1. Introduction 只介紹主題，沒有建立研究問題。
2. 研究缺口只寫「很少研究」。
3. 文獻探討只是作者與年份的排列。
4. 假設只有文獻引用，沒有理論機制。
5. 方法選擇沒有說明理由。
6. Results 依軟體輸出順序呈現。
7. Discussion 只是重複顯著與不顯著。
8. 宣稱因果，但設計只能支持關聯。
9. 宣稱預測能力，但只報樣本內 R²。
10. 宣稱非線性，但沒有線性基準模型。
11. 貢獻與研究結果沒有直接對應。
12. 使用過度強烈但缺乏證據的措辭。
13. 審查者可能誤解的重要概念未事先定義。
14. 結論新增正文未曾分析的主張。
