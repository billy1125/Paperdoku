# 方法紅旗清單（依研究型態）

依論文型態讀對應段落。每項：**徵狀（怎麼看出來）→ 為何是問題 → 方向／該引文獻**。

---

## 〇、通用：研究問題 → 所需證據 → 分析方法

不論論文或計畫，方法章的核心對應是「**每項研究問題都應有對應的證據與分析方法**」。審查時逐項核對下表；找不到對應者即為紅旗。

| 研究問題／主張 | 可能分析方法 |
|---|---|
| 構念是否具信效度 | CFA、PLS-SEM 測量模型 |
| 變數是否具有影響 | 迴歸、SEM、PLS-SEM |
| 是否存在中介效果 | Bootstrap 間接效果 |
| 是否存在調節效果 | 交互作用或多群組分析 |
| 不同條件是否有差異 | t 檢定、ANOVA、ANCOVA |
| 模型是否具預測力 | PLSpredict、交叉驗證（樣本外） |
| 是否存在非線性增益 | ANN 與線性基準比較 |
| 教學介入是否有效 | 前後測、控制組比較、混合模型 |

**紅旗——方法選擇沒有理由**：只列軟體／方法名稱（「本研究使用問卷與 SEM」），未說明「為何此方法能產生回答本 RQ 所需的證據」。
- 方向：改以「為同時檢驗多項潛在構念的直接與中介效果，採 PLS-SEM 評估測量與結構模型」這類**帶理由**的寫法。

## 一、量化（迴歸 / SEM / PLS-SEM / 調查）

**Q1. 測量未對準構念**
- 徵狀：題項措辭把依變項意涵寫進前因（如「技術特徵」題項寫成「很有用、能支援我的任務」＝知覺有用性/契合）。
- 為何：與後續構念套套邏輯，係數高估。
- 方向：重述題項聚焦客觀屬性。

**Q2. 區別效度失敗（Fornell–Larcker，硬證據）**
- 怎麼看：相關矩陣對角線（粗體）為各構念 √AVE；任一非對角相關 **>** 相鄰構念 √AVE 即失敗。
- 範例：A、B 相關 0.909，而 A 的 √AVE 0.873 → 兩者難以區分。
- 方向：**要求補報 HTMT**（門檻 0.85/0.90）；仍高則重新操作化或合併。

**Q3. 構念重疊／汙染**
- 徵狀：兩構念題項描述幾乎同一件事（如「裝置的社交分享功能」vs「使用者的社交分享行為」）。
- 方向：對該路徑解讀保守，勿當重要貢獻。

**Q4. formative vs. reflective 誤設**
- 徵狀：二階構念子維度概念互異、不必然同向共變，卻設為反映性。
- 方向：依 Jarvis et al. (2003) 判準重檢；形成性需報 weights 與 VIF。

**Q5. 不支持假設的負係數 → 先查共線性（抑制效應）**
- 徵狀：某假設不成立、**β 為負**，但其與依變項零階相關理應為正；且相關矩陣多處高相關。
- 為何：典型多元共線性抑制（suppression），變號是假象。
- 方向：**要求補報 VIF**；補後重寫該「反直覺發現」解讀（對作者通常是好消息）。

**Q6. 共同方法偏誤（CMB）**
- 徵狀：僅用 Harman 單因子檢定（不敏感、近乎一定過）。
- 方向：補 marker variable / 潛在方法因子；或誠實列限制。

**Q7. 報告完整性清單（常缺）**
- 必查：效果量 / 信賴區間、**VIF、HTMT、SRMR、f²、間接效果（中介）檢定**。
- 中介鏈卻只報直接路徑 → 要求 bootstrap 間接效果。

**Q8. 方法選用理由站不住腳**
- 徵狀：「樣本相對題項數小所以用 PLS」用在數百份樣本。
- 方向：改以更貼切理由（含形成性構念、探索性目的等）。

**核心理論對照（依變項 → 應對話理論）**
- 持續使用 continuance → ECM, Bhattacherjee (2001)；habit, Limayem et al. (2007)。
- 初始採用 adoption → TAM / UTAUT / UTAUT2。
- 任務—科技 → TTF, Goodhue & Thompson (1995)。
- 社會資本三維度 → Nahapiet & Ghoshal (1998)（常被誤掛 Granovetter）。

## 二、實驗 / 準實驗

**E1. 內部效度威脅**
- 徵狀：無隨機分派或未交代；無對照組；選擇、成熟、歷史、流失等威脅未處理。
- 方向：說明分派方式；補對照；討論並排除替代解釋。

**E2. 操弄與測量效度**
- 徵狀：缺**操弄檢核（manipulation check）**；依變項測量信效度未報。
- 方向：補操弄檢核；報信效度。

**E3. 統計檢定力與樣本**
- 徵狀：無事前**檢定力分析/樣本量計算**；組別過小；只報 p 值無效果量。
- 方向：補 power analysis、效果量與信賴區間。

**E4. 多重比較與彈性分析**
- 徵狀：大量比較未校正；有 p-hacking / HARKing 疑慮；無預先註冊。
- 方向：校正多重比較；區分驗證性與探索性分析；鼓勵預先註冊。

**E5. 生態效度 / 外推**
- 徵狀：高度人工情境、便利樣本（如僅大學生），卻做廣泛外推。
- 方向：誠實界定外推範圍。

## 三、質性 / 個案

**G1. 取樣與飽和**
- 徵狀：取樣邏輯（立意/理論抽樣）未交代；未討論**資料飽和**；樣本過少卻做強主張。
- 方向：說明取樣理據與飽和判斷。

**G2. 分析嚴謹度與透明度**
- 徵狀：未交代分析取徑（thematic / grounded / framework 等）；無編碼流程；缺**編碼者間信度**或共識程序。
- 方向：補分析取徑與編碼程序。

**G3. 可信賴度（trustworthiness）**
- 徵狀：缺 Lincoln & Guba 的 credibility / transferability / dependability / confirmability 相關作為（如三角驗證、member checking、audit trail）。
- 方向：補可信賴度策略。

**G4. 反身性與研究者角色**
- 徵狀：未交代研究者立場、前理解對詮釋的影響。
- 方向：加入 reflexivity 說明。

**G5. 證據與詮釋的連結**
- 徵狀：主張缺引文佐證；引文與詮釋落差；過度概化。
- 方向：以原始資料支撐每個主張。

## 四、混合方法

**M1. 整合的真實性**
- 徵狀：質與量只是並列（兩篇報告釘在一起），未真正**整合（integration）**。
- 方向：說明設計類型（序列/並行/嵌入）與整合點（如 joint display）。

**M2. 階段間的循環論證**
- 徵狀：質性歸納出 N 維度 → 量化用同資料「驗證」同樣 N 維度，當成相互佐證。
- 方向：釐清兩階段獨立性，避免自我證成。

**M3. 各階段自身的嚴謹度**
- 量化看第一節、質性看第三節；兩邊都要站得住。
