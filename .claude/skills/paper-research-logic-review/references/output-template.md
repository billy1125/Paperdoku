# Output Template

## 一、論文總結表

每篇論文佔一行，表格保持簡潔完整。

| # | 論文 | 理論基礎 | 研究架構 | 關鍵假設 | 支持/顯著 | 不支持/不顯著 | 主要發現 | 備註/不確定性 |
|---|---|---|---|---|---|---|---|---|
| 1 | 論文標題、作者、年份 | 主要理論 | 自變數 → 中介/調節 → 因變數 | H1–Hn 精簡形式 | 支持假設及方向 | 不支持/部分/混合/相反 | 2–3 個核心發現 | 提取限制或模糊之處 |

表格過寬時，保持欄位精簡，詳細假設分析移至單篇綜合註釋。

---

## 二、單篇論文綜合註釋

每篇使用相同結構：

```
### [#]. [論文標題]

**基本資料：** 作者、年份、期刊（如有）
**理論基礎：** 主要理論及其如何支持模型
**研究架構：** 變數、路徑、中介、調節、因變數

**假設邏輯：**
- H1：前提 → 機制 → 預期方向；邏輯品質
- H2：前提 → 機制 → 預期方向；邏輯品質

**支持狀態：**
- 支持/顯著：H 值與簡潔結果
- 不支持/不顯著：H 值與簡潔結果
- 部分支持/混合/相反：H 值與簡潔結果

**基本研究發現：** 一段整合討論與結論的簡明段落
**遺漏或不確定內容：** 僅在相關時填寫
```

## 三、批量綜合

分析完所有論文後加入，僅基於已提取論文，不引入外部文獻。

| 面向 | 說明 |
|---|---|
| 共同理論基礎 | 這批論文共同依賴的理論 |
| 共同框架模式 | 中介效應、調節效果、技術接受、行為意圖、績效結果等重複出現的結構 |
| 穩定支持的發現 | 跨多篇重複得到支持的關係 |
| 不穩定或不支持的發現 | 重複未被支持或結果不一致的關係 |
| 研究邏輯觀察 | 假設邏輯與實證支持之間顯著的落差 |

---

## 四、深度分析加值輸出（deep review 模式）

### 變數關係整理
跨篇整理自變數、依變數、中介變數、調節變數，標注哪些關係在多篇中重複出現。

### 理論貢獻評估
整理各篇作者聲稱的理論貢獻，比較其實際檢驗內容是否支撐該貢獻主張。

### 跨論文模式分析
- 哪些理論被廣泛使用但驗證不足
- 哪些變數關係跨情境穩定 vs 不穩定
- 假設邏輯品質的整體分布（強/合格/弱/不清晰的比例）

---

## 品質檢查清單

輸出前確認：

- [ ] 每篇論文在總表中都有一行
- [ ] 每篇論文包含理論基礎（如有）
- [ ] 支持與不支持的結果已分開列出
- [ ] 假設邏輯與實證結果未混淆
- [ ] 方法論細節除非影響結果解釋，否則不贅述
- [ ] 資訊模糊或缺失之處已明確標註
