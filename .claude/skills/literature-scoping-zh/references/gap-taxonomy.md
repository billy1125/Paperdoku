# 研究缺口分類（gap-taxonomy）

「找到研究缺口」是發現期盤點的核心產出，也最容易誤判。本檔給缺口分類與辨識準則，並貫徹**反缺口膨脹**（見 `../_shared/research_design_discipline.md`）。

## 缺口類型

| 類型 | 意思 | 辨識問句 |
|---|---|---|
| evidence gap（證據缺口） | 既有證據衝突、不足或效果不明確 | 各篇結論是否互相矛盾？效果量是否不穩定？ |
| knowledge gap（知識缺口） | 某變數關係／機制尚未被探討 | 有沒有明顯該問但沒人問的關係？ |
| methodological gap（方法缺口） | 既有研究方法有共同侷限 | 是否都用同一種設計/樣本/測量，缺其他方法檢證？ |
| population/context gap（對象/情境缺口） | 結論未在某對象、產業、地區、時期驗證 | 現有樣本集中在哪？哪些對象/情境沒被涵蓋？ |
| theoretical gap（理論缺口） | 缺乏整合框架或理論解釋 | 是否只有零散實證、缺統整理論？ |
| practical/application gap（應用缺口） | 研究與實務落差 | 學理結論是否缺實務場域驗證？ |

一個真正的缺口通常能講清楚：缺什麼、為何重要、若補上會有什麼貢獻。

## 辨識準則

1. **以搜尋結果為據**：缺口必須從**本次盤點納入的文獻**推得，不是憑印象。
2. **附搜尋邊界**：講缺口時一併寫「查了哪些資料源、關鍵字、年份、篩選」——缺口的可信度等於搜尋的完整度。
3. **用保留語**：寫「**在本次搜尋範圍內尚未定位到直接證據**」，不寫「從未有人研究」「這是全新領域」。
4. **排除假缺口成因**：MCP 未涵蓋、非英文文獻、書籍/專著、極新或極舊文獻、關鍵字沒對上——都可能造成「看起來是缺口其實只是沒搜到」。懷疑時換同義詞或另一資料源再查。
5. **區分「缺口」與「我還沒讀」**：只有題名/摘要時，某些看似缺口可能全文其實有處理；標為信心「低」，並建議必讀關鍵文獻經 `source-document-extraction` 抽全文後於後段確認。

## 與下游的接法

- 標定的缺口 → `hypothesis-generation-zh` 把缺口收斂成可檢驗的研究問題與競爭假設。
- 必讀關鍵文獻的可信度存疑 → `scholar-evaluation-zh` 篩查。
- 要對關鍵文獻做全文層級的正式回顧與逐篇 RoB → 後段 `literature-review-organizer`。
