# claim-audit 模式：宣稱查核

目的：針對**特定一個（或幾個）宣稱**，回論文原文查它到底有沒有證據支持、證據與宣稱是否相稱。這是輕量的「證據-宣稱相稱」查核，不是完整同儕審查。

> 本模式是 `../_shared/anti_leakage.md` 的直接應用：**只認原文的證據**。原文沒有的，判為「查無支持」，絕不用記憶替論文補證據或補引用。

## 適用

- 使用者指定某句宣稱（「論文說 X，是真的嗎？」「這個數字有根據嗎？」）。
- 或使用者要你挑出論文中**最關鍵、最需要證據**的幾個宣稱逐一查核。

## 查核步驟（每個宣稱）

1. **鎖定宣稱**：用一句話精確重述被查的宣稱（引原文句子）。
2. **找原文證據**：回論文定位支撐該宣稱的內容——數據、實驗結果、被引文獻、推理段落；引出關鍵原句或數值。
3. **判定相稱**，用固定四級：
   | 判定 | 意義 |
   |---|---|
   | 支持 | 原文有明確、直接的證據，且與宣稱範圍相稱 |
   | 部分支持 | 有證據但範圍/強度不足（如小樣本卻下普遍結論、相關性當因果） |
   | 不支持 | 原文證據與宣稱不符或相反 |
   | 查無 | 原文找不到支撐該宣稱的證據（可能在未讀到的部分——需標明範圍限制） |
4. **說明理由**：1–2 句講為什麼是這個判定，對應到步驟 2 的原文證據。

## 常見不相稱型態（判「部分支持」時可點名）

- 以相關性宣稱因果。
- 小樣本/單一情境卻下普遍結論。
- 引用某文獻支持一個該文獻其實沒講的主張（claim–citation 不符）。
- 把「未顯著」講成「證明沒有效果」。

## 原則

- **逐宣稱、可回溯**：每個判定都附原文定位，讓使用者能自己覆核。
- **讀不到就說**：證據可能在擷取不完整的段落時，判「查無」並註明「限於可讀範圍」（見 `../_shared/confidence_language.md`），不假設。
- **假設支持類宣稱**：涉及「假設是否被支持」時，遵 `../_shared/hypothesis_support_discipline.md`（需作者明示顯著性，不從係數符號猜）。
- **宣稱靠一張圖/表時**：用 `../_shared/figure_fidelity.md`——以 source-document-extraction `--figures` 把該頁 render 成 PNG、用 Read 讀圖，查圖是否真的支撐宣稱（截斷軸、無誤差線等），結果為 advisory。
- **守分寸**：這是單點查核；要完整逐條 Major/Minor 審查與判決，改用 `academic-peer-review-zh`。
