# Extraction Rules

## 來源判讀

接受以下輸入：多個 PDF 檔、多個論文連結、混合輸入。

先判斷每篇文獻的可讀層次：

| 層次 | 說明 |
|---|---|
| 全文可讀 | 可讀到完整 PDF 或完整內文 |
| 部分可讀 | 部分頁面、部分文字或不完整 PDF |
| 僅摘要可讀 | 只有摘要頁、DOI 頁或出版社頁面 |
| 幾乎不可讀 | 只有書目資訊或頁面存取受限 |

所有後續判斷都受可讀層次約束。

## 信心等級標記

每篇文獻標記一個信心等級：

| 等級 | 條件 | 語氣要求 |
|---|---|---|
| 高 | 全文可讀，關鍵欄位完整 | 可用較確定語氣，但避免過度延伸 |
| 中 | 大部分可讀，有少量缺漏 | 加限定語，如「依可讀內容判斷」、「目前資訊顯示」 |
| 低 | 僅摘要、片段或資訊不足 | 明確使用保留語氣，如「初步判斷」、「僅能根據摘要推估」 |

信心中或低時，明確寫出缺少什麼，例如：
- 僅依摘要整理
- 樣本資訊未完全揭露
- 理論框架需全文確認
- PDF 文字擷取不完整

## 擷取欄位

每篇文獻至少整理以下欄位；若不可得，填「未明示」或「無法確認」，不要留白：

- 題名
- 作者
- 年份
- 出處
- 文獻類型
- 研究主題
- 研究問題
- 核心論點 / 主要概念
- 理論基礎 / 理論框架
- 研究情境 / 對象
- 研究方法
- 樣本 / 資料來源
- 分析方法
- 主要發現
- 作者明示限制
- 可辨識研究缺口
- 對後續研究的啟發
- 可讀程度 / 信心等級
- 備註

## 分群規則

遇到以下情況先分群再比較：
- 文獻超過 8 篇
- 主題跨度大
- 理論或方法明顯不同
- 混合不同學門或研究情境

優先分群方式（依序）：
1. 依主題
2. 依理論
3. 依方法
4. 依研究情境或產業

分群後先給群組概覽，再進入各群整理。

## 品質要求

- 不做摘要堆疊，必須做比較與綜整
- 不捏造作者未寫出的結論、理論或研究缺口
- 不把摘要頁資訊誤寫成全文分析結果
- 資訊不足時降低確定語氣並明示限制
- 研究缺口不寫空泛句子（如「未來可擴大樣本」）；要指出可擴到哪類樣本、情境或方法，以及研究意義
- 文獻高度異質時改寫成分群式結論，不硬湊單一結論
