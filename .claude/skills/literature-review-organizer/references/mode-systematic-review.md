# systematic review 模式：PRISMA 系統性回顧

目的：把多篇文獻整理提升為**可重現的系統性回顧**——不只綜整，還要有明確的篩選準則、各階段計數（PRISMA 流程）、逐篇風險偏誤評估。適合真的要寫 SR 的使用者。

> 遵守 `../_shared/anti_leakage.md`（以原文為準）、`../_shared/confidence_language.md`（讀不到收語氣）。RoB 沿用 `../_shared/risk_of_bias.md`，不另立一套。

## 開始前先確立協定（與使用者確認）

系統性回顧的可重現性來自**事前定好規則**。動工前確認：

1. **研究問題 / PICO（或對應框架）**：對象、介入/暴露、比較、結果（依領域可調整）。
2. **納入準則 / 排除準則**：明列（如年份範圍、語言、研究設計、主題邊界、是否只收實證）。
3. **檢索來源**：哪些資料庫/管道取得這批文獻（可搭配 `paper-search` 以 Semantic Scholar 檢索）。
4. **文獻集合**：使用者提供的清單/PDF 即為本次的識別結果。

> 誠實界線：本 skill 不自行跑完整資料庫檢索；它在**使用者提供的文獻集合**上執行透明的篩選與評估。若集合不完整，於報告限制中明示（檢索的完整性影響 SR 效度）。

## 工作流程（PRISMA 四階段）

1. **識別(Identification)**：清點所有取得的文獻，記總數；標記重複並移除，記重複數。
2. **篩選(Screening)**：依納入/排除準則逐篇初篩（標題/摘要層級），記排除數與**主要排除理由**。
3. **符合資格(Eligibility)**：對通過初篩者做全文評估，記全文排除數與理由。
4. **納入(Included)**：確定最終納入篇數，進入資料萃取與綜整。

每階段都要記**計數**與**理由**，這是 SR 與一般整理的關鍵差異。

## 逐篇處理（納入者）

- 依 `extraction-rules.md` 萃取欄位，建比較表（沿用 organizer 既有格式）。
- **逐篇風險偏誤評估**：套用 `../_shared/risk_of_bias.md` 的六面向，給評等與依據。
- 綜整：跨篇一致與分歧、**依證據強度加權**（見 `../../_shared/evidence_hierarchy.md`，與 RoB 併用）、研究缺口。

## 輸出格式

```markdown
## 系統性回顧報告

### 1. 回顧協定
- 研究問題 / PICO：…
- 納入準則：…／排除準則：…
- 文獻來源與集合說明：…（含完整性限制）

### 2. PRISMA 流程
| 階段 | 計數 | 說明 |
|---|---|---|
| 識別 | N 篇（去重後 M） | … |
| 初篩排除 | −A | 主要理由：… |
| 全文排除 | −B | 主要理由：… |
| 最終納入 | K 篇 | — |

（可附文字版流程圖：Identification → Screening → Eligibility → Included，標各階段數字）

### 3. 納入研究一覽 + 風險偏誤
| 研究 | 設計 | 樣本 | 主要發現 | 整體 RoB |
|---|---|---|---|---|
| … | … | … | … | 高/有疑慮/低/不清楚 |

### 4. 綜整與研究缺口
（跨篇一致/分歧、依證據強度、缺口）

### 5. 限制
（檢索完整性、納入偏誤、RoB 對結論的影響）
```

## 紀律

- **每個排除都要有理由與計數**——這是可重現性的核心。
- **不誇大檢索完整性**：在使用者提供的集合上做，完整性限制誠實揭露。
- RoB 依 `../_shared/risk_of_bias.md`，未報告標 unclear 不逕判高風險。
- 與 `citation-verification-zh` 可搭配：需確認納入文獻引用真偽時，呼叫該 skill。
